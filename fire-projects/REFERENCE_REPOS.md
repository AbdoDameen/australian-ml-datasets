# Global Fire Data Science & Analytics — Reference Repos

Comprehensive list of fire/wildfire-related GitHub repositories and Kaggle
datasets, compiled July 2026. Sorted by stars, with notes on relevance.

──────────────────────────────────────────────────────────────────────────────


## ⭐ Top Starred (All Domains)

★ 54  snehitvaddi/YOLOv3-Cloud-Based-Fire-Detection
       Custom YOLOv3 object detection on the cloud to detect fire in video
       frames. Can be used for surveillance camera integration.
       Topics: computervision, deeplearning, fire-detection

★ 50  Otutu11/Forest-Fire-Risk-Prediction
       Random Forest Classifier trained on environmental features. Closest
       open-source match to your Project 1 (risk prediction).
       Topics: machine-learning, random-forest, fire-risk

★ 42  Call-for-Code/Spot-Challenge-Wildfires
       IBM Call for Code challenge. Predicts fire area for 7 Australian
       regions. 28 forks, community solutions. #1 reference for Australian
       focus.

★ 34  Beckybams/Forest-Fire-Spread-Modeling
       Data-driven simulations predicting how wildfires propagate across
       landscapes. Analyses topography, weather, and fuel moisture.
       Topics: simulation, wildfire-spread, data-science

★ 32  Dogiye12/AI-Based-Forest-Fire-Detection-System
       Real-time detection using satellite data (MODIS, VIIRS) and CNN-based
       classification. Good satellite + ML pipeline reference.

★ 25  Beckybams/Wildfire-Risk-Prediction
       Uses synthetic environmental data (temperature, humidity, wind) to
       estimate wildfire probability. Clean classification pipeline.

★ 12  Shashivadan/FireTrack
       Full-stack: satellite imagery + weather data + real-time wildfire
       monitoring. Dashboard reference for Project 4.

★ 11  spaceml-org/pyrocast
       End-to-end ML pipeline for extreme wildfire prediction. Uses causal
       discovery. Best architecture reference — study their pipeline design.

★ 11  stanleyjzheng/BlueSky-AI
       Wildfire prediction with ML. BridgeHacks Hackathon Winner 2020.

★  9  thilak-r/Forest-fire-detection-using-YOLOv8
       Real-time deep learning system using YOLOv8 for fire and smoke
       detection across images, videos, and live feeds. Flask deployment.
       Topics: deep-learning, yolo, flask, forest-fire-detection

★  8  aritrikg/Forest-Fire-Detection-YOLO
       Research-grade computer vision system for forest fire detection using
       YOLO architecture.

★  7  prashantsubedii/ForestSathi
       Intelligent wildfire risk prediction system. HTML/JS frontend. Designed
       for community and forest officer use.

★  6  AdamGit69/AFDR
       Australian Fire Danger Ratings. Directly relevant to Australian fire
       service roles.

★  6  fati-bendaouch/Wildfires-Prediction-Using-Remote-Sensing-Data-and-Machine-Learning
       Remote sensing data + ML for wildfire prediction. Jupyter notebooks.

★  6  shbkukuk/ForestFireDetection
       Comprehensive analysis: deep learning models vs conventional ML
       algorithms for forest fire detection.

★  6  BluEyedTree/ForestFireClassification
       CNN to classify forest fires from images.

★  5  rakshitsharma0402/Forest-Fire-Detection-System
       Early detection using IoT sensors + deep learning algorithms. C++.

★  5  alekhka/forest-fire-deep-learning
       Forest fire detection from satellite imagery using deep learning.
       Python, Keras/TensorFlow.

★  4  thunderhoser/ml_for_wildfire_wpo
       Machine learning for multi-day prediction of fire weather and
       behaviour. Research-grade meteorological focus.

★  4  amal2121/Fire_Forest_Detection
       Deep learning extra project. Jupyter notebook.

★  4  anubhav9369/Forest-Fire-Detection-System
       ResNet50 image classifier. Flask web app.

★  4  007shashi/Forest-Fire-Detection-and-Animal-Monitoring
       CNN + Deep Learning for fire detection and wildlife monitoring.
       Python.
