# Australian Construction Industry

**Domain:** Economics
**Source:** ABS Construction Work Done
**URL:** https://www.abs.gov.au/statistics/industry/building-and-construction/construction-work-done-australia

## Description
Construction work done data across Australia covering both building and engineering construction. Includes value of work by sector (residential, non-residential, civil engineering), by state, and by public vs private sector. Quarterly data from the ABS.

## ML Potential
- Construction activity forecasting
- Economic growth indicator modelling
- Sector-specific trend analysis

## Files
- `raw/` — Raw ABS construction data
- `processed/` — Cleaned work done time series
- `features/` — Engineered features for ML
