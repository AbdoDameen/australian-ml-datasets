# Australian Hospital Admissions

**Domain:** Health
**Source:** AIHW (Australian Institute of Health and Welfare)
**URL:** https://www.aihw.gov.au/reports-data/myhospitals

## Description
Hospital admissions data across Australian public and private hospitals. Includes separation statistics by diagnosis (ICD-10 codes), procedure type, length of stay, admission method (emergency/elective), age, sex, and hospital peer group.

## ML Potential
- Hospital admission forecasting
- Length of stay prediction
- Disease prevalence and trend analysis

## Files
- `raw/` — Raw AIHW data files
- `processed/` — Cleaned admission records
- `features/` — Engineered features for ML
