# Australian Stock Market (ASX)

**Domain:** Finance
**Source:** Yahoo Finance / ASX Historical Data
**URL:** https://au.finance.yahoo.com/

## Description
Historical stock price data for Australian Securities Exchange (ASX) listed companies. Includes open, high, low, close prices, and trading volumes for major ASX indices (ASX 200, All Ordinaries) and individual stocks across all sectors.

## ML Potential
- Stock price prediction and forecasting
- Portfolio optimisation and risk modelling
- Market anomaly detection

## Files
- `raw/` — Raw CSV price data
- `processed/` — Cleaned, aligned time series
- `features/` — Technical indicators and engineered features
