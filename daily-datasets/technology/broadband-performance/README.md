# Australian Broadband Performance

**Domain:** Technology
**Source:** ACCC Measuring Broadband Australia
**URL:** https://www.accc.gov.au/consumers/internet-reports/measuring-broadband-australia

## Description
Broadband internet performance measurements across Australia from the ACCC's Measuring Broadband Australia (MBA) program. Includes download/upload speeds, latency, packet loss, and streaming performance for major ISPs. Data collected from white-box probes in volunteer households.

## ML Potential
- ISP performance classification and comparison
- Network quality prediction
- Broadband speed forecasting

## Files
- `raw/` — Raw ACCC broadband data
- `processed/` — Cleaned performance metrics
- `features/` — Engineered features for ML
