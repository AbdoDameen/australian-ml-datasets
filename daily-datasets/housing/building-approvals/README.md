# Australian Building Approvals

**Domain:** Housing
**Source:** ABS Building Approvals
**URL:** https://www.abs.gov.au/statistics/industry/building-and-construction/building-approvals-australia

## Description
Building approval data for new residential and non-residential buildings across Australia. Includes number of dwelling units approved, type of building (houses vs units), value of approvals, and geographic breakdown by state and LGA. Monthly data from ABS.

## ML Potential
- Construction activity forecasting
- Housing supply prediction
- Economic indicator modelling

## Files
- `raw/` — Raw ABS building approvals data
- `processed/` — Cleaned approval time series
- `features/` — Engineered features for ML
