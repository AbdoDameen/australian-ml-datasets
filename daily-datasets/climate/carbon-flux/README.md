# Carbon Flux (OzFlux)

**Domain:** Climate
**ML Task:** Regression (predict NEP — Net Ecosystem Productivity)
**Source:** Global terrestrial ecosystem 8-day carbon flux dataset (1991–2023)
**Description:** 156,000+ measurements of carbon flux (NEP, GPP, ecosystem respiration) from 414 sites across 41 countries.

## Columns

| Column | Description |
|--------|-------------|
| site_name | Monitoring station name |
| country | Country of the site |
| ecosystem_type | Type (forest, grassland, cropland, wetland, etc.) |
| latitude / longitude | Site coordinates |
| year / day_of_year | When measured |
| nep | Net Ecosystem Productivity (target) |
| gpp | Gross Primary Productivity |
| ecosystem_respiration | Ecosystem Respiration (RE) |
| data_source | Source of the data |

## Data File

`1991-2023全球陆地生态系统8天尺度碳通量站点观测数据集_V2.xlsx` (11 MB) — included in this folder.
