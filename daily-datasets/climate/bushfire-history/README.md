# Australian Bushfire History

**Domain:** Climate
**Source:** data.gov.au / BNHCRC (Bushfire and Natural Hazards CRC)
**URL:** https://data.gov.au/dataset/ — https://www.bnhcrc.com.au/

## Description
Historical bushfire records across Australia including fire perimeters, ignition points, fire severity, area burned, and dates. Covers major fire events and prescribed burns. Includes data from state fire authorities and the BNHCRC historical fire database.

## ML Potential
- Fire risk prediction and classification
- Fire spread modelling
- Burn severity and area estimation

## Files
- `raw/` — Raw bushfire data from data.gov.au
- `processed/` — Cleaned fire records
- `features/` — Engineered features for ML
