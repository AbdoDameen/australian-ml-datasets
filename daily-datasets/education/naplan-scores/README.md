# Australian Education — NAPLAN Scores

**Domain:** Education
**Source:** ACARA (Australian Curriculum, Assessment and Reporting Authority)
**URL:** https://www.acara.edu.au/assessment/naplan

## Description
National Assessment Program — Literacy and Numeracy (NAPLAN) test results for Australian students in Years 3, 5, 7, and 9. Covers reading, writing, spelling, grammar and punctuation, and numeracy domains. Includes school-level and national summary data.

## ML Potential
- Student performance prediction
- Educational outcome classification
- Regional education quality analysis
