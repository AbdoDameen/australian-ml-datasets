# Australian Immigration Statistics

**Domain:** Demographics
**Source:** ABS / Department of Home Affairs
**URL:** https://www.abs.gov.au/statistics/people/population/migration-australia

## Description
Immigration data for Australia including permanent migration, temporary migration (student, skilled, working holiday), humanitarian intake, and net overseas migration (NOM). Covers visa categories, source countries, settlement states, and age/gender breakdowns.

## ML Potential
- Migration flow forecasting
- Settlement pattern analysis
- Demographic impact modelling

## Files
- `raw/` — Raw ABS and Home Affairs data
- `processed/` — Cleaned migration time series
- `features/` — Engineered features for ML
