# Australian Road Traffic Accidents

**Domain:** Transport
**Source:** BITRE (Bureau of Infrastructure and Transport Research Economics) / data.gov.au
**URL:** https://data.gov.au/dataset/road-crash-data

## Description
Historical road crash data from Australian states and territories. Includes accident locations, severity levels, vehicle types, road conditions, speed limits, and contributing factors. Maintained by BITRE for road safety research.

## ML Potential
- Accident severity prediction
- Black spot / high-risk location identification
- Contributing factor analysis and classification

## Files
- `raw/` — Raw CSV data from data.gov.au
- `processed/` — Cleaned, normalised crash records
- `features/` — Engineered features for ML models
