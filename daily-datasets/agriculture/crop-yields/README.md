# Crop Yields (Global)

**Domain:** Agriculture
**ML Task:** Regression
**Source:** SAGE / UW-Madison Global Crop Yield Dataset
**Description:** GeoTIFF rasters for 4 major crops — Maize, Rice, Soybean, Wheat — at 5-minute resolution, 1982–2015

## Crops

| Crop | Files |
|------|-------|
| Maize | 34 yearly GeoTIFFs (1982–2015) |
| Rice | 34 yearly GeoTIFFs (1982–2015) |
| Soybean | 34 yearly GeoTIFFs (1982–2015) |
| Wheat | 34 yearly GeoTIFFs (1982–2015) |

## Data

Raw GeoTIFFs are available on the [GitHub Releases](https://github.com/AbdoDameen/australian-ml-datasets/releases/tag/raw-data-v1) page (`crop_yields_raw.zip`, 95 MB).
