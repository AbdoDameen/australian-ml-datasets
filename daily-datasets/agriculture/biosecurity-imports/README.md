# Australian Biosecurity — Plant Imports

**Domain:** Agriculture
**Source:** DAFF (Department of Agriculture, Fisheries and Forestry)
**URL:** https://www.agriculture.gov.au/biosecurity-trade/import

## Description
Data on plant and plant product imports into Australia, managed by the Department of Agriculture, Fisheries and Forestry (DAFF) for biosecurity purposes. Includes import volumes by commodity type, country of origin, quarantine inspection outcomes, pest interceptions, and biosecurity risk assessments.

## ML Potential
- Biosecurity risk classification
- Import trend forecasting
- Pest interception pattern analysis

## Files
- `raw/` — Raw DAFF biosecurity data
- `processed/` — Cleaned import records
- `features/` — Engineered features for ML
