# Australian Agricultural Commodity Prices

**Domain:** Agriculture
**Source:** ABARES (Australian Bureau of Agricultural and Resource Economics and Sciences)
**URL:** https://www.agriculture.gov.au/abares/data

## Description
Prices for major Australian agricultural commodities including wheat, barley, canola, beef, lamb, wool, dairy, sugar, cotton, and horticultural products. Includes farm-gate, wholesale, and export prices with historical trends.

## ML Potential
- Commodity price forecasting
- Market trend analysis and volatility prediction
- Supply-demand modelling

## Files
- `raw/` — Raw data from ABARES publications
- `processed/` — Cleaned price time series
- `features/` — Engineered features for ML
