# Australian Solar Radiation

**Domain:** Energy
**Source:** BOM / ARENA
**URL:** http://www.bom.gov.au/climate/data/ — http://www.arena.gov.au/knowledge-innovation/

## Description
Solar radiation and irradiance data across Australian locations. Includes global horizontal irradiance (GHI), direct normal irradiance (DNI), diffuse horizontal irradiance (DHI), and sunshine hours. Sourced from BOM weather stations and ARENA solar mapping projects.

## ML Potential
- Solar energy generation forecasting
- Site suitability classification for solar farms
- Climate pattern analysis

## Files
- `raw/` — Raw solar radiation data
- `processed/` — Cleaned irradiance time series
- `features/` — Engineered features for ML
