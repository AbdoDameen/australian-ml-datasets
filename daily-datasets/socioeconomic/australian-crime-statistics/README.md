# Australian Crime Statistics

**Domain:** Socioeconomic
**Source:** ABS (Australian Bureau of Statistics)
**URL:** https://www.abs.gov.au/statistics/people/crime-and-justice

## Description
Recorded crime statistics for Australia at national and state/territory levels. Covers offences across categories including homicide, assault, sexual offences, robbery, burglary, theft, drug offences, and fraud. Also includes victimisation rates and offender characteristics.

## ML Potential
- Crime rate forecasting and trend analysis
- Geographic crime hotspot identification
- Socioeconomic factor correlation analysis

## Files
- `raw/` — Raw ABS crime data
- `processed/` — Cleaned, aggregated crime statistics
- `features/` — Feature-engineered datasets
