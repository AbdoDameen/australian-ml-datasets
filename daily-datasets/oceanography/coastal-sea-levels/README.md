# Australian Coastal Sea Levels

**Domain:** Oceanography
**Source:** BOM / National Tidal Centre
**URL:** http://www.bom.gov.au/oceanography/projects/ntc/index.shtml

## Description
Sea level data from the Australian National Tidal Centre's network of tide gauges around the Australian coastline. Includes hourly sea level measurements, tidal predictions, storm surge events, and mean sea level trends for major ports and coastal locations.

## ML Potential
- Sea level rise trend forecasting
- Storm surge event detection and prediction
- Tidal pattern analysis and anomaly detection

## Files
- `raw/` — Raw BOM sea level data
- `processed/` — Cleaned time series
- `features/` — Engineered features for ML
